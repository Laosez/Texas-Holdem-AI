# Постфлоп V1 — пять игровых архетипов

Пять **основных** постфлоп-профилей в экранe «Реализация», независимо выбираемых для каждого игрока:

| Профиль | Внутренний ID | Механизм |
| --- | --- | --- |
| GTO-inspired Regular | `gto_postflop_v1` | Исходная GTO-inspired эвристика (НЕ solver-equilibrium) |
| TAG Regular | `tag_postflop_v1` | Дисциплина цены колла, вэлью с сильными руками и редкий блеф |
| Smart LAG | `lag_postflop_v1` | Исходная агрессивная LAG V1 эвристика; полублефы, частый C-bet |
| Draw Chaser | `chaser_postflop_v1` | Систематическая переоценка прямых дро; некоторые коллы по невыгодной цене |
| Trapper | `trapper_postflop_v1` | Чеки/коллы с сильными руками; реже слоуплей на мокрых бордах и в мультипоте |

Новые TAG/Chaser/Trapper используют общую с GTO/LAG V1 функцию `read_hand` и легальный расчёт ставок. Они **не** вычисляют оптимальное равновесие или equity против конкретного диапазона соперника. Девять аутов флеш-дро сейчас считаются номинальными и могут включать грязные ауты. Это осознанно **поведенческие** модели для A/B-тестов, а не эмпирическая калибровка по базе реальных игроков.

**Контрольные позиции, видимые в новом селекторе:** `gto` (GTO Old, исторический Monte Carlo) и `random`. Старые `smart`, `tag_punisher`, `wide_defender`, `baseline_sane`, `nit`, `loose_passive`, `maniac`, `maniac_mixed`, `pressure_filler` убраны только из основного выпадающего списка. Их код, имя, выгрузки и конфигурации старых сессий сохранены; они появляются в селекторе при восстановлении старой сессии.

**Новый пресет «5 постфлоп-стилей · 9 мест»:** P1 — A17/GTO V1; P2–3 — PC/GTO V1; P4–5 — PC/TAG V1; P6–7 — PC/LAG V1; P8 — PC/Chaser V1; P9 — PC/Trapper V1. В пресете единый префлоп-протокол и ротация мест. Он предназначен для первого стресс-теста, **не** для оценки популярности типов соперников.

## Дальнейшая оптимизация

1. Заморозить V1 реализации и их хэши для контрольных запусков.
2. Добавить единый постфлоп-анализатор: чистые ауты, equity относительно диапазонов, вероятность фолда и EV доступных действий.
3. Разделить оценку состояния и политику действий игрока; сделать параметры профилей редактируемыми и версионируемыми.
4. Тестировать на одинаковых seed, с ротацией посадки и независимой проверочной выборкой.

Управление составом соперников должно оставаться отдельным от эксперимента по префлоп-диапазонам.
