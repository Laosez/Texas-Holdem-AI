# GTO 5.0 alpha — простые поправки к риверным формулам P0–P3

**Статус:** исследовательский справочник формул, **не** готовая исполняемая стратегия. GTO 4.1/5 — неизменённый вычислительный эталон. Не выпускать этот документ как подтверждение точности автономного GTO 5.0.

## Единое правило

Для одной **готовой** категории руки \(c\):

\[
P_c(\text{street})=\max\{0,\ R_c(P,K,x,H)+a_{P,c}\cdot y\},
\qquad
y=\begin{cases}2 & \text{flop}\\ 1 & \text{turn}\\ 0 & \text{river.}\end{cases}
\]

- \(R_c\) — проверенная **риверная** формула из «SKACHKOV POKER» → «Просто формулы».
- \(K\), \(x\), \(H\) сохраняют договорённые значения: весовые коэффициенты рангов, исходную долю pocket pairs (%) и вероятность готового straight ∪ flush (%).
- Обрезка ниже нуля скрытая, для ручного применения округлять прогноз до 5%; **не** принудительно доводить сумму до 100%.
- Никаких дополнительных поправок по S/F; структура борда уже присутствует в исходных \(K,H\), формулах straight и flush.
- \(P2\) невозможен на флопе. Пустой набор свободных рангов при вычислении \(K_{\mathrm{св}}\) означает нейтральное значение 1.

**Важно:** нулевой коэффициент означает «нет уличной поправки», а не «нулевая вероятность». Если сама риверная база равна нулю по структурной невозможности, готовая категория остаётся нулевой.

Формулы для straight / flush / straight flush оставляем отдельными (S/F/H) и в этой версии не изменяем. Готовые руки не следует складывать с дро как взаимоисключающие категории.

## Проверка 2026-11-04

- Точный перебор двухкарточных рук оппонента без карт борда; 169 взвешенных типов стартовых рук, диапазоны 10%..100%.
- P0: 600 случайных непарных флопов/тёрнов, 120 контрольных бордов. Поправки (+10,−6,−3,−1) были подобраны отдельно.
- P1–P3: 1 100 случайных парных бордов (220 в каждом из сочетаний P1F/P1T/P2T/P3F/P3T); обучение 880, контроль 220 бордов.
- На всех контрольных бордах использовано **точное H**, полученное перебором. Поэтому приведённая ошибка — условная, **не** ошибка будущего человеческого расчёта H.

**Ограничение P1:** на контрольной выборке абсолютная ошибка >5 п.п. остаётся для пары в 25,5% прогнозов, для двух пар — в 28,9%. У узких диапазонов погрешность обычно выше. Не добавляем отдельные S/F-коррекции по решению автора, пока проверяем простоту.

**Не делать:** не подменять готовые распределения формулами дро; не приписывать этим формулам accuracy полноценного EV, win rate или ICM; не утверждать эквивалентность GTO 4.1; не считать модель уже реализованным ботом.

Исходная матрица записана в отдельный лист: **SKACHKOV POKER → 14 · GTO 5.0 · F/T/R**. Существующий «Просто формулы» и продакшен не менялись.


## Shadow Mode: требования к калибровочному отчёту (GTO 5.0 vs GTO 4.1)

**Единица наблюдения** — одно решение Hero в идентичном состоянии стола, а не целая раздача; 5.0 выбирает действие, 4.1 только оценивает то же состояние. Запуск проверки — опциональный (0/10/25/100%), с детерминированным выбором событий без изменения RNG игры. После завершения — анализ отдельно, чтобы не блокировать очередное решение.

**Обязательные разрезы:** F/T/R; 1 / 2 / 3 / 4+ оппонентов (именно оставшихся в раздаче на момент действия); P0/P1/P2/P3/специальные структуры, S и F по принятым правилам Board150; полное пересечение P·S·F; дополнительное пересечение улица × число оппонентов × структура. Префлоп и невалидные борды не включать.

**Метрики для КАЖДОЙ группы:**
- n доступных решений, n выбранных для Shadow, n успешно сопоставленных, n пропущенных с причиной. Для процентов делитель — число успешно сопоставленных, не число раздач.
- Средняя абсолютная разница EV по общим действиям (MAE EV в BB); максимальная разница и p90.
- Decision mismatch (%) и средняя/медианная потеря EV (BB) от выбора 5.0 по функциям ценности 4.1.
- Доля случаев с EV Regret > 1 BB / > 5 BB; сумма EV Regret по группе. Не путать «частоту ошибки» с её «дороговизной».
- Время вычисления 5.0 и 4.1 (CPU + wall), slowdown режима Shadow; число решений на улице и в мультипоте.
- В отдельных столбцах: различие распределения готовых рук, ΔEV и Δdecision — не выводить «ошибка распределения» из одного ΔEV.

**Рейтинги:**
1. «Где ошибается чаще» — mismatch% (только группы с n>=30, сортировка по частоте).
2. «Где ошибается дороже» — средний EV Regret (только группы с n>=30).
3. «Где суммарно теряет больше» — total EV Regret с n и sample coverage.
4. 20 худших отдельных решений с параметрами стола, Hero, историей до действия, временем, обоими EV и референсным доверительным интервалом, если рассчитан.

**Правила сопоставления:** те же Hero-карты, доска, pot, позиции, размер ставки, to_call, текущие стек/блайнды, список оппонентов и доступные действия. Для расчёта EV ставки **сравнивать одинаковый размер**; несопоставимые варианты исключать и учитывать в skipped. Нельзя использовать известные после шоудауна карты оппонентов как вход для оценки старого решения. Чипы нормализовать в BB по актуальному большому блайнду на момент решения.

**Границы достоверности:** GTO 4.1 — приближённый, шумный эталон, поэтому в интерфейсе основной термин «расхождение с GTO 4.1», а не «абсолютная ошибка». Низкие n отмечать «мало наблюдений», не ранжировать. Данные можно экспортировать в CSV/JSON и открыть конкретную раздачу. 100% Shadow может заметно замедлить игру; по умолчанию 25%, режим выключаемый.

**Внедрение:** агрегатор + сбор идентичных снимков + фоновая/отложенная проверка после серии + UI отчёта, все вместе. Этот раздел — спецификация, пока не доказательство работающего Shadow Mode. Перед релизом проверить нулевой эффект на выбранное игровое действие и корректность всех n.
