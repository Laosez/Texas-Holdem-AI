# GTO 5.2 · Старшинство и расследование дорогих Shadow-ошибок

## Две изолированные поправки к GTO 5.1

GTO 5.0 / 5.0.5 / 5.1 / 5.1.5 **не меняются**. Новый профиль gto_postflop_52_5:

1. **Старшая карта:** r_5.2 = r_5.1². Две приватные карты OPP вместо одной ранговой попытки. Это эвристика, не точная вероятность с блокерами и ничьими.
2. **Пара Hero на непарном борде P0:** ранговые маршруты для контакта с бордом и второго свободного кикера с весом available[paired] × available[kicker]. Для карманных пар рангов вне борда добавляются веса C(available[rank],2), то есть 6/3/1 для четырёх/трёх/двух доступных физических карт. Сравниваем ключ пары плюс три старших кикера; при равенстве отдаём половину. Не более 5×13+13 ранговых маршрутов вместо 990 реальных двухкарточных рук. Масти в этих маршрутах не используются — на части бордов это вызывает остаточную ошибку категории.
3. **Другие категории и специальные P4/PH:** правила 5.1 без изменений.
4. **Распределения категорий, x, K, поправки на дро, частоты, размеры ставок и мультипотный EV:** без изменений относительно 5.1.

## Связь 20 самых дорогих ошибок с журналом

Исходный gto5_shadow_decisions.jsonl уже содержит карты Hero, борд, турнир, раздачу, конкретные действия и EV двух моделей. Рейтинг Shadow V2 терял карты Hero при агрегировании; в V3 оставляем их и добавляем shadow_id — точный номер исходной записи. Исторический V2 дополняем только при уникальном совпадении по всем существенным ключам. Неоднозначные соответствия не приписываем.

В новых Shadow записях hand_steps содержит **все постфлоп-решения Hero в той же раздаче**, даже не попавшие в Shadow и на последующих улицах. В старых без hand_steps доступны лишь те шаги, что проверялись Shadow. Пропуски не заполняются догадками. Скрытые карты оппонентов не сохраняются.

Авторизованные маршруты:
- GET /api/runs/{run}/gto5-shadow — агрегат V3 или безопасная стыковка старого V2 с исходными данными;
- GET /api/runs/{run}/gto5-shadow-decision?decision={id} — полный записанный контекст конкретного Shadow-решения;
- GET /api/runs/{run}/gto5-shadow-decision?decision={id}&exact=1 — ленивый точный перебор категории и старшинства Any Two на текущем борде.

На флопе/тёрне точная проверка относится только к **готовым рукам текущей улицы**, без будущих карт. На ривере это точная HU-доля против равномерного Any Two с блокерами Hero и борда, не мультипотный EV и не оптимальное действие. Regret относительно GTO 4.1 — тоже не реальные потери в турнире.

## Следующий эксперимент

Сначала GTO 5.2 → GTO 5.1, чтобы изолировать изменение старшинства. Затем одинаковые игровые состояния GTO 5.1 и 5.2 против GTO 4.1. GTO 5.1 остаётся контрольной версией.
