# GTO 5.3 · Взвешенное старшинство внутри категории

Дата: 2026-11-04. Изолированная версия модели `gto_postflop_53_5` / `gto53`.
GTO 5.0 / 5.0.5 / 5.1 / 5.1.5 / 5.2 сохраняются неизменными.
Реализация: `bots/hand_seniority_53.py`, `hero_seniority_53()`.
Проверка: `test_gto53_weighted_seniority.py`.

## 1. Формула и предел применимости

Рассчитываем долю выигрыша Hero внутри **той же готовой категории** при **Any Two**:

```
r_c = (W_weak + 0.5 W_tie) / (W_weak + W_tie + W_strong)
```

Веса считаются для физических сочетаний с учётом известных карт Hero и борда, но **не перечислением 990 двухкарточных рук**. Проходим не более 91 **пары рангов** (13*14/2), каждый ранговый маршрут имеет аналитический вес.

- Разные ранги `a != b`: `W = (4 - used[a]) * (4 - used[b])`.
- Одна карманная пара `a == b`: `W = C(4 - used[a], 2)`.
- Сравниваем строго лучшие пять карт Hero и OPP с учётом старшинства категории, кикеров и ничьих.
- Если маршрут ОPP даёт **другую категорию**, его вес не входит в знаменатель условного `r_c`.
- При невозможной категории OPP (вес=0) возвращаем нейтральные 0.5 как fallback, но **не** называем это измеренной вероятностью.

### Масти, флеш и стрит-флеш

Если на борде менее трёх карт одной масти, двух приватных карт недостаточно, чтобы создать флеш: суммируем масти в едином весе рангового маршрута.

При `F3+` выбираем масть борда, для каждого ранга `a` разделяем оставшиеся карты:
`s_a = 1`, если карта этого ранга искомой масти ещё свободна, иначе `0`;
`o_a = (4-used[a]) - s_a`.

Для разных рангов `a != b` разбиваем вес на четыре взаимоисключающих случая:

| Масти приватных карт OPP | Вес |
| --- | --- |
| Ни одна не целевой масти | `o_a * o_b` |
| Только `a` целевой масти | `s_a * o_b` |
| Только `b` целевой масти | `o_a * s_b` |
| Обе целевой масти | `s_a * s_b` |

Для карманной пары одинакового ранга обе карты не могут иметь одну масть:
`W_0=C(o_a,2)`, `W_1=s_a*o_a`.

Каждый случай оцениваем по пяти лучшим картам. **Обычный флеш и стрит-флеш разделяем**. Старшинство флеша — пять старших карт соответствующей масти, а не только самая старшая. Стрит: высокая карта лучшего из десяти окон, колесо A2345 считается старшим рангом 5. Общий стрит/флеш на борде и кикеры обрабатываются сравнением лучших пятёрок.

## 3. Фактически пройденные контроли

- Все **22 флеша и 37 стритов** исходной случайной выборки: совпадают численности OPP и `r`; максимальное расхождение менее 0.005 п.п. из-за округления.
- Взвешенный расчёт **265 двух пар, 57 троек и 21 фулл-хауса** ранее сверялся на той же сохранённой выборке и дал отклонения в пределах округления (исключая несопоставимые состояния).
- **240 независимых** случайных состояний FLOP/TURN/RIVER: сравнение с полным перебором всех допустимых физических OPP-карт, **0 несовпадений** по `r` и условному числу рук.
- Регрессионный тест дополнительно сверяет конкретные контрольные раздачи и независимые случайные состояния.

Важно: это **не** доказывает снижение ошибки `P(category)` или прирост chipEV/WinRate. Будущие карты (turn/river) не моделируются внутри `r`. Условное старшинство при наблюдаемом действии оппонента, узкие диапазоны и мультипот — отдельные задачи. Сохраняем существующие `P(category)`, EV, Shadow и порядок решений для A/B.

## 4. Границы ручного применения

Для P0 по конкретным двум парам достаточно 3–10 сравнений с весами 9/6/4 и 6/3/1. Полный универсальный алгоритм до 91 ранговой пары удобен для детерминированного симулятора, **не для устного пересчёта всего пространства за 30 секунд**. Позже можно вывести краткую памятку для узких категорий.
