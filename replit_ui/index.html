01 / Параметры турнира

В режиме V1 диапазоны открытия остаются индивидуальными. Для каждого игрока одинаковы все ответы после чужого входа в банк и размеры рейзов. Это экспериментальная модель, не GTO.

Турниры уже рассчитываются в 1–4 отдельных процессах. Railway автоматически ограничивает их число доступной RAM, чтобы избежать OOM. При увеличении памяти лимит повышается автоматически.

Подключение к Railway

Защищённый API

Полный резервный ZIP позволяет перенести и восстановить все сессии через кнопки выше без перезаписи старых ID. Для защиты от потери Railway Volume сохраняй копию на отдельном устройстве. Автоматический внешний S3-бэкап требует отдельного хранилища.

02 / Стратегии игроков

2–9

Пустое поле означает незавершённую конфигурацию — запуск блокируется. Совпадающие стратегии у разных игроков допускаются.

Random доступен для Preflop и Postflop. Random/Random выбирает допустимые действия и размеры рейзов случайно, без оценки карт. Единый протокол V1 нормализует A17/PC, но не ограничивает Random на префлопе.

№PreflopPostflop

Сохранённые версии из редактора стратегий появятся в Preflop после подключения. Выбор версии фиксируется для турнира; неотредактированные позиции используют исходный алгоритм стратегии.

Исходные стратегии (без стандартизации): GTO (PC) 80 BB — исходные чарты доступны только для RFI (открытие первым), включая BTN (позиция 3; ~53,9% Raise). Частоты округлены до 25%. Защиты BB / 3-bet / 4-bet пока выполняются эвристикой GTO Fixed, а НЕ исходными PC-чартами. Старый GTO скрыт для новых турниров, но прежние отчёты и их воспроизведение сохранены.

GTO V1 — контрольная GTO-inspired эвристика. GTO V2 — исправление двух пар для карманных 22–66 на спаренном борде; не solver. GTO V3 — эксперимент с кикером/парой+дро: A/B пока не показывает устойчивого улучшения EV (против LAG возможное ухудшение); не солвер. TAG V1 — выборочная агрессия, LAG V1 — частые ставки и полублефы, Chaser V1 — переоценка дро, Trapper V1 — слоуплей. Архивные модели не предлагаются для новых сборок; прежние результаты сохранены.
