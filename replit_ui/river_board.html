03 / Справочник физических бордов ривера

150 классов

Один физический ривер-борд → один составной идентификатор P · S · F · SF · A. Точные частоты относятся к случайному пятикарточному борду, без учёта известных карт HERO. Парность — 6 структур, стрит — 6, флеш — 4, стрит-флеш — 6, туз — 2. Физически достижимы только 150 комбинаций из 1 728 формальных.

Пример: P1 · S3 · F4 · SF3 · A0

Коды S1/S3 означают 3/4 подряд, S2/S4 — соответственно три/четыре ранга в пятиранговом окне с внутренними пропусками. Стрит-флеш требует одну и ту же масть. Туз одновременно допускает wheel A-2-3-4-5. Класс не учитывает HERO, поэтому частота борда не является шансом победы.

03 / Финансовая декомпозиция · БДР

Нет расчёта

Основной расчёт и декомпозиция остаются на листе 02 · План; здесь открывается сохранённое финансовое представление того же EV. Отчёт использует последний актуальный расчёт выбранной руки с листа «02 · План». Для вскрытия классифицируется ривер; для фолда — только последняя реально открытая улица. Показатели не пересчитываются при переключении группировок. Разницу комбинаций и кикеры определяет движок по реальному вскрытию.
