02 / Постфлоп · 1 / 2 / 3 / 4+ соперниковРезультат раздач и решения по каждой улице

Результативность — фактический Net BB/100 за раздачи с постфлоп-решением, сгруппированные по числу живых соперников в момент первого постфлоп-решения Hero. Это оценка реализованной доходности, а не рассчитанный EV конкретного действия. Включает все деньги раздачи, в том числе префлоп; один результат учитывается один раз.

1 = Heads-Up (Hero + 1 оппонент); 2, 3 = два и три оппонента; 4+ = четыре и более. Частоты — по реальным возможностям действия, а не по всем раздачам, с разными знаменателями. Матрица против Bet и Raise использует только ситуации, где доступны все три действия. Bet — первая ставка улицы, Raise — повышение. Нет наблюдений — «—», не 0%. Старые турниры без такой телеметрии не восстановить достоверно.

C-bet: успешные продолженные ставки / фактические возможности префлоп-агрессора (turn/river — последовательные баррели после колла без рейза). Fold to C-bet: фолды / случаи, когда игрок столкнулся именно с этим баррелем, не с произвольной ставкой. Для прежних сессий отсутствующие счётчики показываются как «—». AF — отношение агрессивных действий к коллам, не процент; BB/100 — результат всей раздачи.
