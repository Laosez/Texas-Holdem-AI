Для процентов Δ измеряется в процентных пунктах; для AF — в единицах AF, для Net bb/100 — в BB/100. Нет возможности измерения — «—», а не 0%. Статистическая значимость разности не вычисляется без достаточных исходных данных.

Методология: результат выводится только из сохранённых турнирных данных; отсутствие числителя или знаменателя не заменяется прогнозом.
