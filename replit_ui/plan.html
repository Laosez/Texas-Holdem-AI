Диагностика поля · число соперников и размер банка

Справочная статистика модели, не дополнительная настройка: сколько соперников участвовало, каков средний банк и погрешность EV. N берётся из основного селектора симуляций.

После Monte Carlo появятся число соперников, фактический средний банк и прогноз погрешности EV.
0 соперников — все сбросили; Equity выставления определяется при ≥1 активном сопернике.

9 позиций = Hero + 8 соперников. «Ширина диапазона» определяет вероятность входа по комбинациям с учётом блокеров; «0%» исключает место. «Стек всех игроков» задаёт одинаковую глубину для HERO и каждого вошедшего соперника в симуляции EV; не изменяет префлоп-пресеты. Модель не рассчитывает дерево префлоп-торговли и не учитывает зависимость решений соперников.

Расчёт Equity против добавленных соперников

169 рук · Multiway Monte Carlo

Вся матрица 169 рук доступна при N = 250–64 000 на руку. Для больших N используются параллельные CPU-процессы по доступным ресурсам Railway. N × 169 — общее число раздач; N ≥ 16 000 создаёт высокую вычислительную нагрузку. Подробный анализ выбранной руки рассчитывается отдельно. Циклов нет.

Equity и EV рассчитываются против указанных диапазонов и постфлоп-стратегий. «Не учитывать» оставляет только showdown equity.

A/B: общий стек, состав и диапазоны соперников. Число соперников фильтруется без повторного расчёта.

Бухгалтерский отчёт A/B появится после Monte Carlo.

Рука A и стратегия A задаются матрицей и HERO. Для руки B «—» отключает сравнение, «=» повторяет руку A. Графики показывают условный EV в группах 1, 2, 3 и 4+ вошедших соперников; 4+ — взвешенное среднее по числу исходов. «Самая дорогая ошибка» означает наблюдаемую категорию потерь, а не доказанную ошибку стратегии. Δ% = (B − A) / |A| × 100, при A = 0 не определяется. Цвет показывает изменение EV, не статистическую значимость. Не ICM и не GTO-солвер.
